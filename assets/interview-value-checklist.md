# 面试含金量自检清单（Interview Value Checklist）

> 阶段 1 项目设计完成后使用：AI 扮演面试官，对项目做"模拟挑战"，量化项目的含金量。
> **评分 < 6 分 → 项目设计不通过，补生产层后再开工。**

## 三、判定

- **≥ 8 分**：高含金量 ✅ 开工
- **6-7 分**：达标 🟡 开工，但把"没答上的题"列进阶段计划补强
- **< 6 分**：不通过 ❌ 回到设计：补充生产就绪项（至少 2 项）或换更有深度的项目方向

## 四、含金量提升手段（评分不够时参考）

| 手段 | 做法 | 提升维度 |
|---|---|---|
| 加压测 | 用压测工具（wrk/hey/ab）跑出 QPS/延迟数据 | 性能 |
| 做故障演练 | 故意 kill 进程/删除 Pod，验证自动恢复，录下恢复时间 | 弹性 |
| 配监控告警 | 加 Prometheus/健康检查，展示指标和告警截图 | 可观测性 |
| 演练回滚 | 发布坏版本→回滚，记录回滚耗时 | 弹性恢复 |
| 加安全项 | 密钥管理/权限最小化/HTTPS | 安全 |
| 做备份恢复 | 数据备份+恢复演练 | 容灾 |
| 写技术博客 | 把排障故事写成文章（加分项，证明表达） | 真实性/传播 |
