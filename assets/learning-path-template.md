# 多项目学习路径规划

> 可选高级功能。多个学习目标时，规划依赖关系，让项目之间知识点递进。

| 1 | | | |

| 3 | | | |

## 二、依赖关系图

```text
[基础] → [中级] → [进阶]

例：Linux 基础 → Docker 容器 → Kubernetes → 监控(Prometheus) → 可观测性进阶
```

识别规则：
- 前置知识：学 B 需要先懂 A，A 就是前置
- 先基础后进阶，先单机后分布式

| | | | |

## 四、知识递进设计

- 项目 1 覆盖：`[基础概念]`
- 项目 2 覆盖：`[在项目1基础上新增的概念]`
- 项目 3 覆盖：`[进阶概念]`

> 原则：每个项目只聚焦"本阶段新知识点"，复用前面项目已会的，避免重复造轮子。
