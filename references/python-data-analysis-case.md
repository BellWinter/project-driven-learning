# 示例案例库②：Python 电商订单数据分析项目

> **定位**：非运维方向示范案例（数据分析/编程方向），证明"项目驱动学习法"的领域无关性。

- **学习目标**：Python 数据分析（pandas + matplotlib + 数据清洗 + 可视化）

## 排障记录示例（阶段 4，真实案例）

### 问题：matplotlib 中文显示为方块
- **现象**：图表标题中文全部显示为 □□□
- **根因**：matplotlib 默认字体不含中文字符
- **解决**：`plt.rcParams['font.sans-serif'] = ['SimHei']` + `plt.rcParams['axes.unicode_minus'] = False`
- **教训**：中文环境第一步先设字体，避免最后统一返工

### 问题：pandas 读大文件内存吃紧
- **现象**：读取 10 万条数据内存涨到 1.5G+，机器卡顿
- **根因**：默认把数值列读成 float64，未指定 dtypes
- **解决**：读入时指定 `dtype`（订单号用 string、金额用 float32）+ 只读需要的列 `usecols`
- **教训**：大数据处理第一步就考虑 dtypes 和列裁剪

### 问题：csv 中文编码报错
- **现象**：`UnicodeDecodeError: 'utf-8' codec can't decode`
- **根因**：数据文件是 GBK 编码
- **解决**：`pd.read_csv(path, encoding='gbk')`，或统一转 UTF-8 预处理
- **教训**：拿到数据先确认编码，别默认 UTF-8
